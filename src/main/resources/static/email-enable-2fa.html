Ative a Autenticação de Dois Fatores (2FA)

Olá,

Para garantir a segurança da sua conta, habilitamos a autenticação de dois fatores (2FA). Siga as instruções de configuração abaixo.

1. Baixe um aplicativo autenticador como Google Authenticator, Authy, ou similar.
2. Escaneie o QR Code abaixo usando o aplicativo.

3. Após escanear, você receberá um código temporário no aplicativo.
4. Insira esse código no campo de validação para completar a configuração do 2FA.

Se precisar de ajuda, entre em contato com nosso suporte.
